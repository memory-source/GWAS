# GWAS 项目独立模拟审稿（2026-10-17）

**结论：按 NeurIPS / ICML / ICLR 完整研究论文标准，我对当前正文倾向 Reject；对最新主动谱层析分支倾向 Weak Reject。主动分支值得继续，但目前不能直接认定为“顶会 ready”。** 这是本次模拟审稿判断，不代表任何会议的实际录用决定。

项目的实验资产明显多于一份初步构想：已有真实 1000G 基因型、多种控制、原始 JSON，以及真实 PLINK 输出读回。主要缺口在于贡献是否足够新、攻击权限是否在实际系统成立、关键对照是否公平，以及有限精度下到底恢复了什么。继续增加同一种随机划分，不能替代这些证据。

## 审查设置与边界

对象包括 paper/main.tex、被动实验 S10/S48 等，以及最新 S61–S66 代码、原始结果和声明。主文仍是 “The Diagnostics Release Is the Leak”，最新主动谱层析结果尚未进入主文。本次按两个实际版本分别评价，避免用新实验替旧正文补充未写出的贡献。

采用三个侧重点不同的审稿视角，评价技术正确性、原创性与意义、应用可信度与表达。未虚构审稿人身份。会场定位以用户要求的顶会为准，不采用 Nature 的选刊门槛。

本次实际执行了：重算 S10 的 25 次种子均值和配对 bootstrap 区间；重放 EAS chr22 五次划分的随机子空间对照；用当前审计钩子做临时合成数据出口探针；独立运行小型合成代数见证。PLINK、全套 GWAS 和全部主动实验未重新运行；其数字属于核对已有原始结果，不称为本轮独立全量复现。已有 PASS / ready 记录只用于查找材料，不作为审稿结论依据。

## 审稿意见一：技术正确性与实验解释

**倾向：Weak Reject。** 线性机制可以成立，但若干排除性论证和外推尚不充分。相关读者包括基因组隐私、成员推断和联邦分析研究者；他们会关心额外输出究竟增加了多少可用信息。

最扎实的基础是：成员、非成员、参考样本分开；S10 的 PC 定向使用校准集，未发现用测试标签选方向；AF 条件化确实是从已发布统计量扣除已知成员，而非调用未知诚实成员；主动恒等式中的私有矩阵用于评估，攻击测量由输出特征对和合作方已知贡献构造。这些设计应保留。

### 1. 已复现的问题：无谱输出对照与主攻击采用不同预处理

主攻击直接对标准化样本做投影范数（[S61:305](../../code/s61_spectral_tomography.py#L305)）；无谱输出对照额外把数值截到 ±5（[S61:339](../../code/s61_spectral_tomography.py#L339)、[S61:447](../../code/s61_spectral_tomography.py#L447)）。S66 换坐标系后，两个标准化对照空间仍使用该截断（[S66:63](../../code/s66_control_provenance.py#L63)）。

本轮固定同一 EAS chr22 缓存、五次划分和随机 k=10 子空间，只改变截断：

| 对照 | 五次划分平均 AUROC |
|---|---:|
| 截断到 ±5 | 0.463450 |
| 不截断，与主攻击一致 | 0.578875 |

不截断五次分别为 0.5340、0.6339、0.5872、0.5545、0.5848。这里仍使用联合中心和尺度；因此它是“没有额外谱输出”，并非“没有任何来自诚实队列的统计量”。信号可能来自已公开预处理、队列内单态位点和投影的共同作用。

这足以否定“这组对照接近随机，因此信号完全来自额外谱对象”的排除性解释。**它没有证明主动攻击相对条件化 AF / 单次谱基线的增量失效。** 应把所有主攻击与对照置于同一位点筛选、中心、尺度和截断下，再比较增量。复现记录见 [control_clipping_checks.json](control_clipping_checks.json)。

### 2. 已核对的结果：PC 优势取决于 AF 基线

从 S10 原始 25 行重算：

| 攻击 | 平均 AUROC |
|---|---:|
| 未条件化 AF | 0.832436 |
| 校准 PC | 0.878575 |
| 未条件化 AF + PC | 0.935391 |
| 给定相同已知成员信息的条件化 AF | 0.940730 |

条件化 AF 在 25/25 个种子上超过 PC；组合的均值也比条件化 AF 低约 0.00534。正文 [main.tex:388](../../paper/main.tex#L388) 已经披露这一反例，不能把它描述为作者隐瞒。问题是章节标题 “The Diagnostics Release Dominates” 和整体贡献仍容易给出更宽的印象。

现在能支持的是“PC 对某个未条件化 AF 攻击增加信息”。尚缺真实数据上的同信息条件化 AF，以及“条件化 AF + PC”相对条件化 AF 的增量。不能从现有组合结果推导“PC 在强 AF 之外没有信息”，也不能推导相反的普遍优势。

### 3. 统计稳定性不能当作独立外部验证

主动实验通常是同一 1000G 面板的五次划分，区间由五个差值 bootstrap 得到（[S61:604](../../code/s61_spectral_tomography.py#L604)）。本轮重放中，EAS seed0 的 120 位诚实成员与其余四次分别重合 29、27、30、35 人。chr1 与 chr22 来自同一批来源受试者，属于染色体复查，不是独立队列复制。

这些区间可以描述固定面板下的划分稳定性；它们不覆盖新队列、新批次、家系或部署差异。不宜简单指责 bootstrap “错误”，应先说明它估计的随机性范围。

TPR@FPR 由测试集经验 ROC 上搜索阈值得到（[common.py:374](../../code/common.py#L374)）。这是标准描述性 ROC 指标，但不是校准集定阈值后的部署误报率。EAS 五个测试集只有 30–46 位非成员，5% FPR 仅约允许 1–2 个误报；“TPR=1”应配数量和区间，不能直接解释为现实筛查能力。

### 4. 精度、规模和科学代价仍限制核心结论

归档 chr22 q8 结果中，float32 下散度重建相对误差约为 EUR 1.81、3pop 2.90、EAS 1.71；保留 4 位小数时，相对强被动基线的 AUROC 增量分别为 −0.0213、−0.1061、−0.0336。真实 PLINK 导出仍保留 EUR 的小幅成员信号，是重要正面证据；它不等价于稳定恢复散度矩阵。

S61 是 chr22/chr1 前缀，chr22 约 3271–3743 个 SNP；S62 的样本扩展只有一个嵌套阶梯，不能建立大队列规律。科学代价又主要是一个模拟二分类表型的 λGC 和八个因果位点的最小 p 值（[S61:570](../../code/s61_spectral_tomography.py#L570)）。它们变化小，只能支持这些摘要指标的相对稳定，不能替代假阳性、功效、效应偏差和完整个体 QC。

技术、原创性、意义和可读性的综合判断是：局部机制可信，外推有限；最需要修的是对照可比性与实际工作点，而非继续压窄固定面板的置信区间。

## 审稿意见二：原创性与学术贡献

**倾向：当前被动正文 Reject；主动路线有更明确的可研究增量。** 本稿对发布对象审计有用，但 ML 顶会需要更清楚的普遍问题与超出现有知识的答案。安全测量论文可以凭扎实实证成立，并非必须提出新密码协议或定理。

被动部分不能把“PCA 会泄漏成员、小训练集更危险、更多主成分可能更危险”作为新发现。[Zari 等 2022 作者全文](https://ps.tm.kit.edu/downloads/publications/zari22membership.pdf)已直接研究 PCA 成员推断、样本量、主成分数与 DP 防护。本文 Related Work 也承认不是新攻击原语。值得保留的增量是 GWAS 场景下的信息公平比较、参考负例偏差，以及发布合同与运行条件的具体测量。

主动路线更有希望。其核心在固定且已知的预处理下满足：

`(C_H + K_t)V_t = V_t Lambda_t`

攻击者知道自己的贡献 K_t，因此：

`Y_t = V_t Lambda_t - K_t V_t = C_H V_t`

多个最终输出提供不同测量方向。恒等式本身是直接线性代数；独立小型合成检验也可复现它：24 个特征、k=3，八次输出的秩从 3 增到 24，恒等式相对残差约 1.3e-15，恢复误差约 1.7e-10。这验证代数入口，不证明高维现实攻击。

[Hartebrodt 等 2023](https://link.springer.com/article/10.1007/s10618-023-00983-z)已研究由联邦 SVD 迭代消息拼接线性方程恢复协方差；[Truth Serum](https://arxiv.org/abs/2204.00032)已研究通过控制自己的训练输入放大隐私泄漏。本项目仍可能有新内容：**内部消息不可见、只用少数最终截断输出，在离散基因型与边际计数保留约束下取得额外信息。** 不能因这些近邻存在就判定本项目已被完全覆盖，也不能把已知线性代数再包装成首次发现。

最新实验已经越过“只有构想”的阶段：真实 1000G、跨染色体复查、真实 PLINK 导出读回均存在。chr22 随机策略 q8 相对所测强被动基线的增量为 EUR +0.0151、3pop +0.1233、EAS +0.0126；PLINK 的 EUR 归档增量为 +0.01397，区间 [+0.00736,+0.02058]，5/5 划分为正。不能忽略这些结果。

但自适应策略没有稳定击败随机交换；“可设计测量”的算法优势尚未建立。若主张理论贡献，需要给出输入预算、谱间隙、输出精度与可辨识性的非平凡关系；若走安全实证路线，则需要现实接口和可复现的操作性收益。两者都不应被低维满秩例子代替。

## 审稿意见三：部署、治理与论文可评估性

**倾向：Reject。** 关心协作 GWAS 的系统开发者和数据管理者需要知道具体哪个对象被谁解密、谁可修改输入、何时可重新拟合。当前对真实系统的引用与本地接口实验之间仍有缺口。

### 1. 关键部署引文不足以支持明文载荷共享

[main.tex:203](../../paper/main.tex#L203) 用 SF-GWAS 支撑“释放研究拟合载荷供各站点投影”。然而 [SF-GWAS 正式作者 PDF，Methods 第 7 页](https://davidfroelicher.com/publication/sfgwas/sfgwas.pdf)明确描述联合计算的 PCs 在后续计算中保持加密，最终共同解密的是关联统计量。该引文不能直接证明本稿所需的明文 loadings + eigenvalues 接口。

[SF-PCA §5 Step 8](https://pmc.ncbi.nlm.nih.gov/articles/PMC11044025/)允许按应用要求选择性解密 PCs 和/或投影数据，也允许保持加密。可选接口值得研究，但必须指明具体解密对象和接收者，不能推成所有联邦 GWAS 的默认行为。

本地 PLINK 的 `--pca allele-wts` 读回证明软件能够导出该对象，没有证明某个协作部署允许攻击方反复变更基因型、固定诚实队列重新拟合并取得明文输出。应把“有这些权限时成立的风险”与“已验证系统暴露”分开。

### 2. 已复现的问题：所谓唯一出口并未成立

[enforce.py:38](../../code/enforce.py#L38)只拦截有限事件，未建立 OS 层文件系统隔离。提取当前钩子放入新子进程后，本轮得到：

- 普通 `open(...,"wb")` 被 SandboxViolation 拦截，文件未产生。
- 普通 `os.mkdir(.../"SYNTHETIC_VALUE_042")` 成功，外部可观察的编码目录确实产生。

探针只使用临时合成数据，无 root、无 ctypes 或主动加载原生代码；结束后临时目录自动清理。这是普通 Python 在现有边界内的文件系统出口。虽然它不否定 manifest 对经由其 API 的对象校验，却足以否定“子进程只有一个可写出口”“所有普通 Python 自然出口已封闭”的强表述。

[Python 官方文档](https://docs.python.org/3/library/sys.html#sys.addaudithook)也说明 audit hooks 不适合充当沙箱。若保留系统防护贡献，应建立实际文件系统/网络权限隔离并验证；否则将其定位为合作式发布检查器。修补一个 mkdir 事件不是完整出口保证。

### 3. 攻击权限与科学有效性需要逐项成立

主动分支同时假设已知精确联合中心与尺度、允许合作方修改个体间块对应关系、多次重新拟合，以及取得约一半校准成员的完整基因型与标签（[S61:411](../../code/s61_spectral_tomography.py#L411)、[S61:438](../../code/s61_spectral_tomography.py#L438)）。基线获得同样信息是优点；仍需要明确这些信息来自何处，并降低已知成员比例做消融。

保留逐 SNP 直方图会保留 AF、逐位点 HWE 等函数，但不自动保留个体杂合度、亲缘、跨块 LD 和样本真实性。现有材料承认个体杂合度会变，审稿时不能把它写成“通过完整 QC”。

### 4. 主文与最新研究问题脱节

本轮按空白计数得到摘要约 818 词，混入大量例外、旧实验与运行说明。正文仍以被动 PC/AF 排序和治理为核心，最新主动路线未进入主文。两条研究线分别涉及被动发布接收者、可修改输入的恶意合作方，以及受约束的工作流作者，权限和结论不能混用。

应选择一个主问题，围绕一张核心结果图组织贡献。对 ML 读者，需要先解释可推广的学习或识别问题；对安全读者，需要先固定攻击合同与可验证部署；实现细节移至方法或附录。

## 综合裁决与最小验收条件

三份意见的共同判断是：**已有真实而有用的测量结果，但“内部审计通过”“有限合同下可写成测量稿”与“顶会贡献成立”不是同一件事。** 本次没有看到足以推翻整个主动恒等式或全部成员增量的证据；同样也没有看到足以消除上述拒稿理由的材料。

| 审查对象 | 本次建议 | 主要原因 |
|---|---|---|
| 当前被动正文 | Reject | 直接先行工作强，宽泛 PC 优势被同信息 AF 缩小，真实发布接口引文不足 |
| 最新主动分支 | Weak Reject，建议继续 | 有真实最终输出证据，但关键对照不一致、权限合同未落地、精度与外部验证不足 |
| 唯一出口防护主张 | 不接受当前强表述 | 普通 Python 文件系统出口已被本轮合成探针复现 |
| 项目继续投入 | 保留主动路线 | 最有潜力的增量是受约束输入下、少次最终输出带来的新增测量能力 |

投稿前最小修改建议，按决定性排序：

1. **先统一对照并固定主结论。** 相同位点、中心、尺度、截断和校准信息；同时报告不增加谱输出、单次条件化 AF/谱、两者联合、随机多次与自适应多次。验收是主增量在公平处理后仍成立，或据反例缩小主张。
2. **固定一个可核验发布接口。** 写清参与者、明文对象、预处理来源、输入修改与重跑授权、输出精度和次数；用实际协议或明确配置端到端复查。不能只凭“某软件可以导出”推断部署暴露。
3. **验证现实工作点。** 用独立受试者来源或队列复查，扩大样本和位点范围，扫描已知成员比例；阈值在校准集固定，测试集报告实际误报人数、FPR 和区间。若范围始终很小，题目与结论同步限定。
4. **分别验收成员推断和矩阵恢复。** 在实际导出精度下比较输出次数、扰动预算和强基线；恢复量给误差与奇异值敏感性。成员信号存活不能替代稳定算子恢复。
5. **用科学效用检验防护和攻击代价。** 重复模拟表型，测假阳性、功效、效应偏差和完整 QC；若保留出口防护贡献，用真正权限边界验证，否则缩回 manifest/API 检查范围。

这些是消除当前主要拒稿理由的可验收证据，不是录用保证。当前最优先工作是前两项；在它们解决前继续堆同面板种子或治理功能，较难改变审稿结论。
