Method Description

The paper is a controlled measurement study of membership leakage from released statistics in multi-site GWAS. Pipeline: (1) Panels. Three ancestries of 300 individuals each are simulated under a Balding--Nichols model ($F_{ST}=0.08$) and split three ways disjointly into study members, an attacker reference panel, and independent non-member targets; an msprime 3-population demography and real 1000 Genomes Phase-3 chr22 pseudo-sites (EUR/EAS/AFR) serve as cross-checks. QC keeps MAF $\in[0.05,0.95]$. (2) Release objects. Each run emits the workflow's released quantities: per-site allele frequencies, the study-fitted PC basis (eigenvalues, loadings, scores), $\lambda_{GC}$, and a missingness table, at several precision/visibility tiers (F2 top-$k$; F4 AF-1dp; F3 AF-2dp; F5 AF-full; F5 per-site). (3) Attacks. An allele-frequency likelihood-ratio membership score plus two functional-form variants (correlation, learned squared-deviation), and a study-fitted PC projection-distance attack; an ancestry/structure-only control projects both target panels onto an independent reference basis (chance by construction). (4) Measurement. AUROC and TPR@FPR$\le$1% with bootstrap CIs, per-ancestor breakdowns, and a cross-validated logistic meta-attack for marginal leakage of intermediate reveals. Data flow: simulator/real-VCF $\to$ release_objects $\to$ attack scores $\to$ metrics JSON in results/raw/ $\to$ tables/figures in the paper. All steps are CPU-only, seeded, and traceable 1:1 from paper numbers to results/raw/*.json.

Method Description

The method is a controlled membership-inference measurement harness for the intermediate objects a federated multi-site GWAS releases (per-site allele frequencies, the study-fitted PCA spectrum, missingness/QC tables) rather than only the final association statistic. It builds matched panels — study members, an attacker reference panel, and an independent non-member set, all drawn disjointly from the same structured population (parametric Balding-Nichols, or real 1000G chr22 splits) — computes the released objects with the standard GWAS pipeline (QC, PCA, marginal association), and scores membership with an allele-frequency likelihood-ratio attack, a release-fitted PC projection-distance attack, and a structure-only control that projects both target panels onto an independent reference basis. Metrics are AUROC and TPR@FPR≤1% with bootstrap CIs and per-ancestor breakdowns; a cross-validated logistic meta-attack measures the marginal leakage of each intermediate reveal. Data flow: simulator/real-VCF → release_objects → attack scores → metrics JSON in results/raw/ → tables and figures in the paper. All steps are CPU-only, seeded, and traceable 1:1 from paper numbers to results/raw/*.json.

Method Description

The paper measures \emph{membership-inference leakage} of the objects a multi-site GWAS releases, and builds a governance layer over those objects. Given a phased or dosage genotype panel, a study set is split three ways into disjoint \emph{study members}, attacker \emph{reference}, and independent \emph{non-members}; every attack is a per-individual score that must rank members above non-members (AUROC). The attack families are: an allele-frequency likelihood-ratio (pooled, per-site/stratum, at several release precisions); a projection-distance attack on the study-fitted PCA spectrum (loadings vs a random-basis / reference-fitted-basis control, and an out-of-sample transfer check); a haplotype/LD and a phase-IBD longest-shared-run channel measured in centiMorgans; and a membership-correlated per-SNP call-rate channel. A joint out-of-fold logistic attacker measures the multi-object \emph{bundle} against its strongest single object. Results are reported on a parametric Balding--Nichols simulator, an msprime recombination-realistic demography, real 1000G Phase-3 chromosomes, and a Li--Stephens mosaic biobank-scale cohort (GPU Gram-PCA).

The governance layer: a declarative \emph{reveal manifest} names each quantity and its declared precision; an \emph{egress monitor} applies the precision and blocks undeclared quantities; a hash-chained \emph{ledger} records cross-run refinements. The binding is a process-isolation runtime (PEP-578 audit hook denying write-opens/sockets/subprocesses/ ctypes, one sanctioned pipe to the monitor, child stdout/stderr discarded). Data flow: panel $\rightarrow$ three-way split $\rightarrow$ attack scores per release object $\rightarrow$ AUROC / per-individual $A^\ast,\rho,\varepsilon$ summary $\rightarrow$ manifest-governed release with monitor + ledger.
